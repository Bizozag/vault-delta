# Desktop 应用壳设计与验证记录

日期：2026-09-08

对应实施计划：Task 18。

## 设计方向

界面采用深墨绿色侧栏、暖灰工作区和青绿色强调。2026-09-09 后续迭代移除了左下角“本地模式、无网络、无遥测”状态块。

窗口默认尺寸为 1280 × 780，最小支持尺寸为 1024 × 680。字体按平台回退：Windows 优先 Segoe UI Variable Text / Microsoft YaHei UI，macOS 优先 PingFang SC；路径和规则使用等宽字体回退。

## 信息架构

固定侧栏包含三个任务域：

1. 比较快照：建立旧快照到新快照的增量补丁。
2. 补丁与恢复：检查、应用补丁以及恢复未完成事务。
2026-09-09 后续迭代移除设置页，导航只保留比较快照与补丁恢复。

顶部区域随当前页面更新标题和说明，并保留统一的“准备就绪”状态。底部状态栏持续显示事务状态、本地执行声明和应用版本。

## Task 18 边界

- 导航只切换本地 ViewModel 状态，不读取或修改文件。
- 文件选择、补丁打开、恢复记录等按钮以完整禁用态展示，等待 Task 19/20 接入真实工作流。
- 比较页明确表达“基线 → 目标”，并展示全部普通文件参与比较、安全检查始终启用。
- 补丁页将“检查并应用”和“恢复未完成事务”并列，避免把恢复能力隐藏在异常流程中。

## 可访问性与状态

- 导航按钮提供 AutomationProperties.Name。
- 所有导航项可通过标准按钮焦点和键盘激活。
- 任一时刻恰好一个页面及导航项处于选中状态。
- 空状态说明下一步会出现什么内容，不使用只有图标的无文字状态。
- 暂未接线的操作使用禁用态，避免误导用户认为功能已经可执行。

## 自动化验证

独立 `VaultDelta.Desktop.Tests` 项目使用 Avalonia Headless、Skia 和 xUnit v3：

- 在 1024 × 680 最小尺寸加载真实 App 与 MainWindow。
- 验证默认显示比较页，另外两页隐藏。
- 验证比较与补丁恢复导航切换，设置入口与页面不存在。
- 在 1280 × 780 渲染两页 PNG，并验证像素尺寸和非空文件大小。

本地视觉复核结果：中文字体回退正常，三个页面无裁切或横向溢出，侧栏选中态、禁用态和空状态均清晰可辨。
