# 固定打包进度与状态提示精简设计

日期：2026-09-09
目标版本：0.1.2

## 问题

页头“准备就绪”和页脚“未开始事务”没有提供可操作信息。ZIP 生成虽然已有阶段、百分比和当前路径数据，但进度卡位于比较页滚动区域顶部；用户在差异列表底部点击生成按钮时，原滚动位置不变，因此进度不可见。

## 设计

- 移除页头右侧“准备就绪”徽章。
- 移除页脚左侧“未开始事务”提示，保留居中的本地处理说明与右侧版本号。
- 将唯一的 `PatchBuildProgressPanel` 从 `ScrollViewer` 内移动到主内容层。
- 进度面板固定在内容区右下角，只在 `IsGeneratingPatch` 为真时显示。
- 面板继续展示生成阶段、0–100% 确定进度条和当前处理路径，不复制第二套进度状态。

## 验证边界

- 默认界面不得再渲染“准备就绪”或“未开始事务”。
- 生成 ZIP 时进度面板可见，扫描面板不可见。
- 进度面板的视觉祖先中不得存在 `ScrollViewer`，确保任意滚动位置都可见。
- 进度值仍由 `PackageBuildProgress` 驱动；复制、压缩、验证和发布阶段保持单调递增。
- 完成、取消或失败后退出 `GeneratingPatch`，固定面板自动隐藏。
