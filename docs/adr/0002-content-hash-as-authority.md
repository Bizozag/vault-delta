# ADR-0002：以 SHA-256 内容哈希作为一致性依据

## Status

Accepted

## Context

时间戳可能因复制、压缩、文件系统精度和时区变化而失真。只比较大小会漏掉等长内容变化，但对所有文件无条件哈希可能很慢。

## Decision

大小和时间戳用于快速筛选；正式 DiffSet、补丁载荷、Apply 基线和最终校验以 SHA-256 为权威依据。哈希通过流式读取计算。

## Consequences

### Positive

- 能识别时间戳相同的内容变化。
- 能验证传输损坏。
- 可支持可靠的重命名候选匹配。

### Negative

- 首次扫描或严格模式需要读取大量文件内容。
- 大库在机械盘上的耗时可能明显。

## Alternatives Considered

- 仅时间戳和大小：快，但不足以作为数据安全依据。
- MD5：速度快但抗碰撞能力不足。
- BLAKE3：性能好，但需要额外依赖；可作为未来实现。
