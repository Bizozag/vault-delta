# Vault Delta 0.1.11

包含 node_modules 目录联接的笔记库以前会停在“无法安全完成比较”，且不显示真正原因。现在错误提示会显示快照、相对路径和处理方式；用户可明确勾选“跳过链接”后继续。

- 扫描不跟随联接、符号链接或重解析点；默认仍停止。选择跳过后，将两侧链接路径的并集及其子目录同时排除，避免误删同路径普通文件。
- 比较结果显示排除路径；生成 ZIP 时另存 `.excluded-links.json`。链接关系仍需在目标电脑单独恢复。
- 若将被删除或替换的父目录中包含排除链接，停止比较，避免连同链接一起移除。
- 风险分类使用一次建立的路径索引，差异列表只渲染可见项，并限制扫描进度刷新频率。
- 文件读取、持续写入和链接错误保留具体路径；迟到的进度事件不会把已完成状态改回扫描中。

验证：Windows 上格式检查、Release 编译及 217 项测试通过。真实大型笔记库比较识别 7 个目录联接，97,937 项变更操作与原校验包逐项一致；差异分类从约 159 秒降至 0.30 秒，包含哈希扫描的整次比较约 138 秒。性能数据来自同一台本机，实际耗时依磁盘和文件数量变化。

本次发布提供自包含 Windows x64 ZIP 和 SHA-256 校验文件。
